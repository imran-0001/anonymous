# 🎮 Number Guessing Game

## About the Project
This is a simple number guessing game built with Python.
The computer chooses a secret number, and the player tries to guess it correctly.

## 🛠️ Technologies Used
- Python

## 🎯 What I Learned
- Using variables
- Taking user input with input()
- Using while loops
- Applying if and else statements
- Using break to stop a loop

## 🚀 How to Run the Game
1. Install Python on your computer.
2. Download the project files.
3. Open a terminal in the project folder.
4. Run the command:

   python guessing_game.py
